# 大月下 · 陪伴版

在月下动作包（摩天轮包及之前合并的全部动作）上增加三件事：

1. **大月下语音**：用本机训练好的 GPT-SoVITS v2Pro 大月下音色（`yuexia`，s1234，GPT G20 + SoVITS S25）朗读她说的话，按语气标签自动选 8 种情绪参考音。
2. **联动与派活**：可选接入 Codex 或 DeepSeek Harness。她会跟着你在这两个工具里的工作说话；你也可以让她**替你把任务派给 Codex 或 DSH**，并在卡片里看进度、批准操作、收结果。
3. **月下卡片 + 控制台**：精简的「月下卡片」（参考白龙桌宠）用来聊天、派活、看 Codex 额度与 DeepSeek 余额；红月风格的「月下 · 控制台」只放设置。

原来的动作、送礼和右键菜单全部保留；原动作包不做任何修改。

## 启动

| 文件 | 作用 |
| --- | --- |
| `启动月下陪伴版.cmd` | 透明桌宠 + 头顶气泡（双击即可） |
| `打开月下控制台（浏览器）.cmd` | 只启动服务，在浏览器里打开控制台 |
| `检测运行环境.cmd` | 安装或换电脑后运行一次：检查程序、素材、显卡与语音环境 |

桌宠上点右键，最下面多了：**和月下聊天 / 派活…**（打开月下卡片）、**月下控制台…**（设置）、**联动**（独立陪伴 / Codex / DeepSeek Harness）、**语音** 开关。点头顶气泡也会打开月下卡片。

**单击待机的月下**会弹出「状态卡」（参考白龙的微型状态面板），再点一次收起；鼠标不停在上面时 8 秒后自动收起。双击仍然是原包的摩天轮，拖动不会弹出。状态卡上有：

- 顶部滑块选 **Codex** 或 **DSH**（记住上次的选择；没选过时跟随联动设置），旁边是会话数；按钮依次是刷新、聊天（打开月下卡片）、控制台。
- 两行会话状态：她派的活、你在所选工具里正在进行的会话；需要批准时标红。
- 左边：选 Codex 时是 5 小时剩余、每周剩余和重置时间；选 DSH 时是 DeepSeek 账户余额（充值 / 赠送），余额低于 ¥1 时标红提醒。
- 右边：所选工具的 Token 用量（全部 / 30 天 / 7 天柱状图）。
- 底部：所选工具的今日 Token，点「24h ›」切换成最近 24 小时的分时柱状图。
- Codex 和 DSH 的本机日志都会读取，所以两边随时都能切换查看；但只有控制台「联动」里选中的那个工具会让月下出声提醒。

Token 只读本机日志统计：Codex 按会话累计值的增量计数（与白龙一致，不会重复），DSH 取每次模型回复的用量。首次在后台扫描全部日志（本机约 720MB、6 秒），之后只读新增部分，结果缓存在数据目录的 `usage-cache.json`。

## 她的话从哪里来

| 你在做什么 | 谁来回答 | 用谁的额度 |
| --- | --- | --- |
| 卡片选「闲聊」，和她说话 | OpenAI 兼容接口（默认 DeepSeek `deepseek-flash`） | 你保存的 DeepSeek API 密钥 |
| 卡片选「Codex」，让她派活 | 本机 Codex（`codex app-server`），在任务目录里干活 | 你本机登录的 Codex 账号额度，不需要密钥 |
| 卡片选「DSH」，让她派活 | DeepSeek Harness 无头模式（`dsh headless`），在任务目录里干活 | 同一个 DeepSeek API 密钥（只作为环境变量交给 DSH） |
| 你在 Codex / DSH 里自己工作 | 不回答，只读本机日志，开始 / 完成 / 出错时说一句固定台词 | 不调用任何接口 |
| 启动问候、试听语气 | 固定台词 | 不调用任何接口 |

派活的结果和你的话写在同一条时间线里，并标上「交给 Codex」「DSH」等标签；派活记录不会进入闲聊的上下文。

## 月下卡片

- **头部**：切换闲聊 / Codex / DSH；刷新额度；打开控制台；收起。
- **状态行**：正在进行的会话（她派的活，或你在 Codex / DSH 里的会话）。
- **额度**：Codex 的 5 小时剩余、每周剩余和重置时间（与白龙一样通过 `account/rateLimits/read` 读取）；DeepSeek 官方账户余额。打开卡片时读取，5 分钟内用缓存，点刷新立即重读。
- **会话**：闲聊、Codex、DSH 各有自己的会话列表。点「☰ 会话名」展开列表：点击切换，双击或 ✎ 改名，🗑 删除（点两次确认）；「＋ 新建」开一个新会话。新会话用第一句话当名字。
  - 闲聊会话：每个会话有自己的上下文，发给模型的只有当前会话的最近几轮。
  - Codex 会话：记住对应的 Codex 对话 ID，切回旧会话继续派活时用 `thread/resume` 接着原来的上下文；DSH 会话记住会话 ID，用 `--session-id` 接着做。
  - 已经开始过的派活会话固定在原来的任务目录里；想换目录请新建会话。
  - 删除只删月下这里的记录，Codex / DSH 里的对话还在。正在执行任务的会话不能删。
  - 旧版的单条记录在第一次启动时自动按闲聊 / Codex / DSH 拆成三个会话。
- **派活栏**：选择任务目录（新会话用）；工作中可以「停止」；Codex 会话上有「在 Codex 打开 ↗」。
- **原样的步骤**：派给 Codex / DSH 的任务，每一步都按顺序记进聊天框并保存在会话里：
  - Codex：中途的说明、推理摘要、计划、运行的命令（完整命令、输出、退出码）、改动的文件（diff）、搜索、工具调用的参数与结果；最终回答作为结果消息，不重复记步骤。
  - DSH：用 DSH 自己的步骤编号；思考、说明、工具调用的参数与结果（调用和结果合成一步）。
  - 说明和计划直接展开，其他步骤折叠成「步骤 n · 类型 · 标题 · ✓/✗」，点开看原样内容（单步超过 2 万字时截断并注明省略了多少）。结果消息上注明「共 N 步 · 用时」。
  - 输出里的乱码（例如 PowerShell 按系统编码读 UTF-8 文件）是工具自己的输出，月下不做改动。
- **批准**：Codex 要运行命令或修改文件、超出权限时，卡片里会出现「允许 / 拒绝」，她也会提醒你。权限在控制台「联动 → 让月下派活」里选：只读 / 可修改任务目录内的文件（默认）/ 完全访问。
- 派给 Codex 的对话会写进 Codex 的对话记录（名字以「月下：」开头）。Codex 桌面版不会自动刷新列表，点「在 Codex 打开 ↗」用 `codex://threads/<ID>` 链接（与白龙相同）让 Codex 直接打开这个对话，不用重启。
- 派给 DSH 的会话会写进 DSH 的会话记录，但 DSH 桌面版没有对外的打开链接（`dsh://` 只能把窗口调到前台），它的本机服务又需要内部令牌，所以只能在重启 DSH 后看到；在月下这边可以随时查看和接着做。她自己派出去的会话，日志联动不会重复提醒。
- DSH 无头模式不会在中途请求批准，按 DSH 自己的权限设置执行。

## 需要的东西都在本目录里

- `runtime\electron\`：自带 Electron 43.3.0。服务端也用它的 Node 模式运行，不需要另装 Node、DSH 或 dsh-pet。界面语言包只保留了中文和英文。
- `pet\`：从摩天轮包挑出的运行时文件，共 87 个：页面与脚本、manifest、59 段动态 WebP、9 张图、9 条配音。不含 webm 备用编码、首尾帧 PNG、无损源和复现资料。在本机用硬链接放入，不额外占空间；`pet\BUNDLE.json` 记录了来源和文件清单。
- 换成新的动作包：`set ELECTRON_RUN_AS_NODE=1` 后运行 `runtime\electron\electron.exe tools\bundle.cjs pet <动作包目录>`。
- 发给别人：运行 `tools\bundle.cjs dist <目标目录>`，只导出运行需要的文件（不含测试和开发文件），大小约 2.1GB，主要是动作素材。
- 没有 `runtime\` 时，也可以在本目录运行 `npm install`，会装同一版本的 Electron。

**唯一不在本目录的是 GPT-SoVITS 语音环境**（默认 `D:\Development\GPT-SoVITS`，包含 Python 环境和大月下权重）。可以在控制台「语音 → 高级」里改位置；没有它时，桌宠照常用文字气泡。

## 语音：有显卡就用显卡

启动语音服务前会先检测显卡：

- 有 NVIDIA 显卡，且语音环境里的 PyTorch 支持 CUDA：用 GPU、半精度运行。
- 有 NVIDIA 显卡，但 PyTorch 是 CPU 版：控制台用黄色提示需要安装 CUDA 版 PyTorch，暂时用 CPU。
- 只有 AMD 或 Intel 显卡（GPT-SoVITS 只支持 CUDA），或者没有独立显卡：用 CPU，并写明原因。

本机的检测结果：AMD Radeon 核显，PyTorch 为 2.14.0+cpu，所以用 CPU，每句大约需要语音时长的 2–3 倍时间。控制台「语音 → 合成设备」可以改成「优先显卡」或「始终用 CPU」。设备只改动陪伴版自己生成的配置副本（`数据目录\voice-server.cuda.yaml` 或 `cpu.yaml`），原 `voice-server.yaml` 不动。

其他说明：

- 9880 端口上已经有语音服务在运行（例如 Lover 项目启动的）时直接复用。陪伴版只会停止自己启动的语音服务。
- 关闭桌宠时，自己启动的语音服务会一起退出。
- 固定的提醒台词在第一次合成后会缓存，之后几乎没有延迟。
- 语音服务还在载入时，说的话会排队等待，不会丢掉声音。
- 默认只在月下待机时出声，不会盖过动作自带的配音；开始表演时，气泡会收起。

## 联动

两种方式都**只读本机日志**，不需要安装任何插件，也不读取推理过程、工具参数或输出：

- **Codex**：读取 `%USERPROFILE%\.codex\sessions\**\rollout-*.jsonl`，思路与白龙桌宠的 `enhanced_core` 相同。
- **DeepSeek Harness**：读取 `%USERPROFILE%\.dsh\sessions\<工作区>\session-*\session.v4.jsonl.zstd`。DSH 每次追加写入一个 zstd 帧，这里按字节偏移只解压新增的帧，取 `turn/start`、`tool/call`、`turn/end`、`session/title`。

另外几点：

- 子代理会话不提醒。
- 桌宠启动前就有的历史记录不会补发提醒。
- 开始任务的问候 45 秒内最多一次；工具切换只换气泡文字、不出声，20 秒内最多一次。

## 对话

闲聊走 OpenAI 兼容接口，默认地址是 DeepSeek 官方 `https://api.deepseek.com`，没填模型时用 `deepseek-flash`。在控制台「人设与模型」里保存 API 密钥即可，可以点「获取模型列表」换成 `deepseek-v4-pro` 等。

- 密钥只保存在本机数据目录的 `settings.json` 里，页面和接口都不会返回原文；粘贴时多带的空格或说明文字会被自动去掉。
- 默认人设根据官方宿舍档案与语音台词的性格写成，可以在控制台修改，也可以恢复默认。

## 数据与安全

- 数据目录：`%LOCALAPPDATA%\YuexiaCompanion`，里面有设置、对话记录、语音缓存（最多 400 句）和日志。
- 服务只监听 `127.0.0.1:18766`，并且校验 Host 和 Origin，写操作必须带自定义请求头，其他网页无法改设置或读取对话。
- 没有任何窗口连接 10 分钟后，服务会自动退出。
